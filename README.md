# Sticker Website

A small Vite + React + TypeScript starter configured for a sticker shop.

## Quick start

1. Install dependencies:

```bash
npm install
```

2. Start dev server and open http://localhost:5173/

```bash
npm run dev
```

3. Build for production:

```bash
npm run build
npm run preview
```

## Fonts
This project uses a local `NRT` font included in `src/assets/fonts`. The project applies `NRT` as the default font.
